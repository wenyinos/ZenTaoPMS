## 本次更新（9.10.5 → 9.10.6）

> **移动端模板层重做**：手机/平板统一为单列卡片式布局；**无数据库结构变更**，桌面端 ≥1280px 保持 10.1 原布局。

### 移动端模板层

- **断点扩展**：响应式层从 ≤767px 扩展到 **≤1279px**，覆盖手机与平板；解除 10.1 皮肤在 `#header` / `#main` 上的 `min-width:1280px`。
- **顶部与二级导航**：标题、主导航、搜索、用户栏纵向排列；模块菜单与页面操作各占一行。`#pageNav` / `#pageActions` 取消桌面绝对定位，并复位桌面脚本写入 `#subNavbar .nav` 的 `left/max-width`，菜单不再被推到屏幕外。
- **仪表盘**：左右栏改单列；欢迎块统计磁贴两列；流程图在手机上改为“角色卡片 + 步骤列表”，平板保留表格。
- **列表与详情**：`.main-row` 主/侧栏堆叠；宽表在容器内横滑；列表固定批量操作栏 `.table-footer.fixed-footer` 改为表格后的普通行；详情页底部操作条 `#mainActions` 改为文末操作区，不再遮挡内容。
- **表单与弹窗**：`.table-form` 标签与控件纵向堆叠；“影响版本”多选与创建/刷新/所有按钮分行；登录页/弹窗（`header.lite`）共用移动样式；安全提示条改为普通流式布局。
- **桌面端**：≥1280px 布局不变，仍为 `col-main + col-side` 双栏。

### 升级说明

- 本版**无数据库结构变更**，但代码版本号变为 `9.10.6`，仍需执行升级流程写入数据库版本号：
  ```bash
  php bin/ztcli 'http://<your-host>/upgrade-execute.html'
  php bin/ztcli 'http://<your-host>/upgrade-afterExec.html'
  ```
- 全新安装的 `db/zentao.sql` 无需变更。
