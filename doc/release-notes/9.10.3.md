## 本次更新（9.10.2 → 9.10.3）

> **社区功能三项 + 通知渠道重整**：无数据库结构变更，覆盖解压即生效。
> webhook 渠道调整为「企业微信 / 飞书 / 默认」，移除已停用的钉钉与倍洽；
> 新增两张社区透视报表与公开 README 徽章端点。

### 变更：webhook 通知渠道重整

渠道列表由「倍洽 / 钉钉 / 默认」调整为 **「企业微信 / 飞书 / 默认」**：

- **新增企业微信群机器人**：按 `msgtype=markdown` 发送，标题加粗置于正文首行。
- **新增飞书自定义机器人**：按 `interactive` 卡片 + `lark_md` 发送，标题进卡片头部，
  正文中的 markdown 链接可点击（纯文本消息会丢失链接，故采用卡片形态）。
- **移除钉钉与倍洽**：两者均已停用。相关分支、消息构造方法与语言项全部删除；连带清理了
  仅为倍洽服务的收件人手机号 / 邮箱查询及其配置项 `needAssignTypes`。
- **遗留记录处理**：库中若存在类型为 `dingding` / `bearychat` 的历史记录，编辑页会把它们
  显示为「默认」（不会静默改写成其他渠道），保存后即归为默认类型。这类记录**不会自动迁移**，
  请按需重新配置或删除。

### 新增：社区贡献报表（2 张内置透视表）

透视表页新增分组「社区」：

- **贡献者排行**：按操作人统计操作总数、涉及对象数、完成任务数。
- **社区健康**：按产品统计 Bug 总数、已解决数与平均关闭时长（天）。

两张表由内置配置在首次访问透视表页时自动写入（按 `code` 幂等，不会覆盖手工改过的报表），
无需手工建表。

### 新增：README 徽章端点

新增公开只读的 SVG 徽章端点 `/badge.php`，供 README 等外部页面嵌入：

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `type` | `openbugs` / `openstory` / `latestrelease` | 未关闭 Bug 数 / 未关闭需求数 / 最新发布版本名 |
| `product` | 产品 ID（可选） | 限定产品维度；省略则统计全站 |

- 只输出聚合数字与版本名，**不暴露标题、指派人等内部字段**；
- 响应带 `Cache-Control: max-age=300`；
- 如需关闭，在 `config/my.php` 中设置 `$config->badge->enabled = false;`。

### 是否建议升级

- **建议**。三项均为增量：渠道重整只影响新配置（既有「默认」类型记录不受影响），报表与徽章为纯新增。
- 升级方式：可直接覆盖解压（本版无数据库结构变更）。首次访问透视表页时自动补入两张报表。
- 使用 webhook 的站点请注意：**钉钉与倍洽渠道已移除**，原先使用这两类渠道的通知需改用
  企业微信或飞书，或退回「默认」（自定义 JSON）。
